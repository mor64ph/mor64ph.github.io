  • Implemented BCPNN and MGPS disproportionality scoring with empirical-Bayes shrinkage — five hyperparameters fitted by MLE across all 33,852 cells, so the prior is learned from the data rather than assumed.

Cross-Patient Seizure Detection

Live Clinical EEG Machine Learning

Machine learning on the CHB-MIT scalp EEG corpus

Detecting epileptic seizures in scalp EEG for patients the model has never seen. The hard part is not the classifier — it is building an evaluation you can trust when positives are three in a thousand and every patient's brain looks different.

  • Built a streaming ingest for a 45 GB corpus under a 26 GB disk ceiling — download, verify checksum, extract features, delete raw, checkpoint — peaking at 6.3 GB and completing all 686 EDF files with zero checksum failures.
  • Evaluated under leave-one-subject-out cross-validation across 23 patients, and quantified the cost of getting the protocol wrong: random splits inflate PR-AUC by 0.18 to 0.40 depending on the feature view, so no single "inflation number" is quoted for the dataset.
  • Caught two metric traps that silently flatter a model. Means-of-ratios: fold-averaged precision read 0.23 against a pooled 0.004 — a 62× gap — so metrics are pooled from summed confusion counts. Gameable false-alarm rates: a DummyClassifier scored 185 of 185 seizures at 0.89 alarms/hour because FA/h counts alarm runs, so time-in-alarm is reported alongside it.
  • Established that threshold and run-length cannot be tuned separately — a sequentially chosen pair detected nothing — and replaced it with a joint search.
  • Fixed three upstream data bugs the corpus hides: MNE silently renames duplicate channel labels in 654 files, one summary file misattributes a seizure end time, and the WFDB annotation AUX field is a byte length rather than a clock increment — each of which corrupts labels without erroring.
  • Pipeline is governed by a binding RULES.md of 43 numbered rules and covered by 138 tests, with every measured constant recorded so it is never re-derived.

Live Sports Analytics

Football match outcome and scoreline prediction

A prediction engine for top-tier football, taken deliberately to its accuracy ceiling before shipping. Elo supplies the outcome probabilities; a Dixon-Coles grid is rescaled onto them so scorelines, expected goals and over/under markets can never contradict the match result.

  • Benchmarked Elo, Dixon-Coles and XGBoost on a fully held-out season, selecting on log loss with paired bootstrap significance tests rather than point estimates — which showed a 46-feature XGBoost was statistically indistinguishable from a 2-parameter Elo.
  • Measured that blending bookmaker odds adds exactly nothing: both linear and logarithmic pooling selected weight 0.00 on validation. Odds are shown in the UI for comparison and never used to alter a prediction.
  • Mapped the remaining headroom instead of guessing at it — every feature-based avenue was exhausted, leaving team news and lineups as the only live lever. Knowing where the ceiling is was the deliverable.
  • Serves from a FastAPI backend with a Vercel frontend, refreshed by a GitHub Actions job that rebuilds Gold data and commits it back to trigger redeploy; a Databricks + Delta Lake path exists for local model builds and is bypassed in production by design.
  • Trimmed the deployed image to fit a 512 MB tier by pinning library versions to the environment that wrote the model pickles and swapping xgboost for xgboost-cpu, dropping 252 MB of unused CUDA payload.

Compass

LLM Application

AI job-search copilot with a provider-agnostic model layer

A copilot that scores how well a role fits a real CV, surfaces the gaps, and drafts tailored applications. Built on the thesis that the job market has a volume problem rather than a tooling problem — so it never scrapes a job board and never submits on your behalf.

  • Built a provider-agnostic LLM layer over Anthropic, Google Gemini and Ollama, so the app moves between hosted and fully local models without a single change at the call sites — and degrades gracefully when a provider's free tier withdraws a capability.
  • Scored job-description fit with all-MiniLM-L6-v2 sentence embeddings running locally, falling back to a lexical similarity backend when the model is unavailable, so the core feature never hard-depends on a download or a key.
  • Encoded the product's ethical constraints as executable tests: the suite fails the build on a banned scraping library, a restricted-platform URL, a submit-shaped route, or an LLM call appearing inside the deterministic quality gate.
  • Kept the quality gate and ATS checker free of model calls by design — they are the brake on the system, so their behaviour has to be reproducible rather than sampled.
  • Parses and rewrites résumés across PDF and DOCX with layout introspection, exporting ATS-safe documents.

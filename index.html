ReportScope

LivePharmacovigilance

Drug-safety signal detection over the FDA adverse-event database

A pipeline and lookup tool over openFDA FAERS that surfaces drug–reaction pairs worth a human looking at. Every score is a closed-form, auditable statistic over a 2×2 table — the design regulators require — with bias diagnostics shipped beside each result rather than buried.

33,852scored drug–reaction pairs
361drugs · 305 molecules
20.7MFAERS reports scanned
22 / 22known-answer controls pass
  • Implemented BCPNN and MGPS disproportionality scoring with empirical-Bayes shrinkage — five hyperparameters fitted by MLE across all 33,852 cells, so the prior is learned from the data rather than assumed.
  • Validated against a known-answer harness: reproduces the statin–rhabdomyolysis reporting odds ratio of 12.96, and independently recovered cerivastatin — withdrawn in 2001 — as the highest-scoring statin without being told.
  • Engineered around hard API limits: date-partitioned the query space to defeat a 25,000-record pagination cap, and collected severity outcomes in 1,444 calls instead of 135,408 by bucketing reactions per drug per outcome.
  • Built an active-comparator diagnostic separating molecule effects from delivery artifacts — exenatide device leakage collapses from 36.23 to 1.01, showing the signal was the injector, not the drug.
  • Deployed as a containerised Flask service with PostgreSQL, Alembic migrations, accounts, email verification and a weekly digest driven by GitHub Actions.

Cross-Patient Seizure Detection

LiveClinical EEGMachine Learning

Machine learning on the CHB-MIT scalp EEG corpus

Detecting epileptic seizures in scalp EEG for patients the model has never seen. The hard part is not the classifier — it is building an evaluation you can trust when positives are three in a thousand and every patient's brain looks different. The live app runs the full pipeline on a recording in the browser — load the bundled sample to see it end to end, no upload needed.

980 hEEG ingested
686 / 686files, 0 checksum failures
352,742labelled windows
138tests · 43 binding rules
  • Built a streaming ingest for a 45 GB corpus under a 26 GB disk ceiling — download, verify checksum, extract features, delete raw, checkpoint — peaking at 6.3 GB and completing all 686 EDF files with zero checksum failures.
  • Evaluated under leave-one-subject-out cross-validation across 23 patients, reaching 0.31 PR-AUC against a 0.004 majority baseline, and quantified the cost of getting the protocol wrong: random splits inflate PR-AUC by 0.18 to 0.40 depending on the feature view, so no single inflation number is quoted for the dataset.
  • Caught two metric traps that silently flatter a model. Means-of-ratios: fold-averaged precision read 0.23 against a pooled 0.004 — a 62× gap — so metrics are pooled from summed confusion counts. Gameable false-alarm rates: a DummyClassifier scored 185 of 185 seizures at 0.89 alarms/hour because FA/h counts alarm runs, so time-in-alarm is reported alongside.
  • Established that decision threshold and run-length cannot be tuned separately — a sequentially chosen pair detected nothing — and replaced it with a joint search.
  • Fixed three upstream data bugs the corpus hides, each of which corrupts labels without erroring: MNE silently renames duplicate channel labels in 654 files, one summary file misattributes a seizure end time, and the WFDB AUX field is a byte length rather than a clock increment.

ScoutIQ

LiveSports Analytics

Football match outcome and scoreline prediction

A prediction engine for top-tier football, taken deliberately to its accuracy ceiling before shipping. Elo supplies the outcome probabilities; a Dixon-Coles grid is rescaled onto them so scorelines, expected goals and over/under markets can never contradict the match result.

3,504held-out test matches
0.9932Elo outcome log loss
0.025measured gap to the market
Dailyautomated data refresh
  • Benchmarked Elo, Dixon-Coles and XGBoost on a fully held-out season, selecting on log loss with paired bootstrap significance tests rather than point estimates — which showed a 46-feature XGBoost was statistically indistinguishable from a 2-parameter Elo.
  • Measured that blending bookmaker odds adds exactly nothing: both linear and logarithmic pooling selected weight 0.00 on validation. Odds appear in the UI for comparison and never alter a prediction.
  • Mapped the remaining headroom instead of guessing at it — every feature-based avenue was exhausted, leaving team news as the only live lever. Knowing where the ceiling is was the deliverable.
  • Serves from a FastAPI backend with a Vercel frontend, refreshed by a GitHub Actions job that rebuilds Gold data and commits it back to trigger redeploy.
  • Trimmed the deployed image to fit a 512 MB tier by pinning library versions to the environment that wrote the model pickles and swapping xgboost for xgboost-cpu, dropping 252 MB of unused CUDA payload.

Compass

LiveLLM Application

AI job-search copilot with a provider-agnostic model layer

A copilot that scores how well a role fits a real CV, surfaces the gaps, and drafts tailored applications. Built on the thesis that the job market has a volume problem rather than a tooling problem — so it never scrapes a job board and never submits on your behalf. Deployed as a genuine multi-user app with per-user data isolation and cost caps, so the live link opens a sign-in page rather than a shared demo.

3interchangeable LLM providers
Localembeddings, no API key needed
Enforcedconstraints fail the build
  • Built a provider-agnostic LLM layer over Anthropic, Google Gemini and Ollama, so the app moves between hosted and fully local models without a single change at the call sites — and degrades gracefully when a provider's free tier withdraws a capability.
  • Scored job-description fit with all-MiniLM-L6-v2 sentence embeddings running locally, falling back to a lexical similarity backend when the model is unavailable, so the core feature never hard-depends on a download or a key.
  • Encoded the product's ethical constraints as executable tests: the suite fails the build on a banned scraping library, a restricted-platform URL, a submit-shaped route, or an LLM call appearing inside the deterministic quality gate.
  • Kept the quality gate and ATS checker free of model calls by design — they are the brake on the system, so their behaviour has to be reproducible rather than sampled.
  • Parses and rewrites résumés across PDF and DOCX with layout introspection, exporting ATS-safe documents.
